### Tips:
- Type `help` to see an overview of the program and useful commands.
- Type `clear` to clear the screen.
Try typing `ls` to see the directories in the root directory, such as `skills`, `education`, etc.
- To see the content of a particular directory, you can type `ls [directoryName]`. Say, for example, `ls skills`.
- To see the content of a particular entry/ file, you can use `cat [fileName]`. For example, `cat whoami` gives a bit of info about me!
- To change directories, use the `cd` command. For example, `cd skills` will take you to the skills directory.
- You can use absolute paths for `cd`, `ls` and `cat`. For example, use `cat /education/ubc` while in any directory to view the `ubc` file's contents~
